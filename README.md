# 👨‍💻 About Me

Computer Science & Engineering student specializing in **Cyber Security** at **Lovely Professional University (LPU)** (2022–2026). Passionate about building **high-performance cloud-native architectures**, **AI/IoT-powered telemetry platforms**, distributed systems, and modern interactive web experiences.

- 🏎️ **ApexF1**: Architecting the ultimate Formula 1 2026 dashboard with real-time telemetry simulation, Three.js 3D livery designer, and AI paddock assistant (NVIDIA NIM & Gemini API).
- 📦 **Inventrox-OS**: Building an AI-powered enterprise operating system for SMEs—demand forecasting, smart inventory management, supplier relations, and automated GST billing.
- 🌍 **EcoGeoGuard**: AI + IoT landslide prediction and agricultural monitoring system using multi-sensor LoRa telemetry; research accepted and presented at **DASGRI Congress 2026**.
- 🏥 **HealthTech & Surgical Systems**: Engineering modern digital workflows and medical visualization interfaces.
- ☁️ **AWS Cloud Architect**: Designing resilient serverless solutions utilizing Lambda, DynamoDB, API Gateway, Step Functions, SQS/SNS, EventBridge, and IAM least-privilege security.
- 🛡️ **Cyber Security & Hardening**: Focus on cloud security posture, network defense, threat modeling, and cryptographic integrity.
- 👥 **Former CEO of Student Organisation SAPPHIRE**: Directed a 20+ member cross-functional team overseeing university-scale technology operations and event management.
